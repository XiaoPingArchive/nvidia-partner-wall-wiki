# NVIDIA 诸神之墙 · 交互式 AI 生态黄页与深度研学系统

本仓库是一个用于深度研究英伟达（NVIDIA）全球 AI 合作伙伴网络与供应链版图的交互式 Web 维基系统。它收录并拆解了 NVIDIA 2026年 Computex（台北电脑展）上展出的 **13 行、共 285 家全球合作伙伴与核心机构**，同时收录了黄仁勋在台湾的非正式商务美食与趣味彩蛋。

---

## 🌟 核心功能

1. **双排版交互视图**：
   - **网格排版**：按行分类的直观卡片流，支持快速搜索、多维度过滤。
   - **大图高亮交互**：基于 Computex 现场高清大图（SVG Mask 全局遮罩开孔技术），鼠标悬停或单点具体 Logo 自动变暗未识别区域并高亮选中企业，并精准定位坐标。

2. **沉浸式研习模式**：
   - 点击“开启沉浸式研习模式”，可进入全屏学术 PPT 研读导览。
   - 支持逐个企业、分行章节自动导航，并附带针对英伟达生态定位的“深度观察（Research Blog）”报告。

3. **智能生态关系研判**：
   - 系统基于各公司的主营业务与 NVIDIA 技术，自动研判其属于：
     * **芯片基石 / 算力底层**（台积电、海力士、美光等）
     * **算力装配 / 落地推手**（富士康、广达、英业达等）
     * **具身智能与物理 AI**（1X、Figure、宇树科技等）
     * **网络与数据安全**（Zscaler、CrowdStrike、Palo Alto 等）
     * **科研大脑 / 行业探路者**（斯坦福、台大、中央研究院等）
     * **模型先锋 / AI应用玩家**（OpenAI、Anthropic、Adobe 等）

4. **台北美食与趣味花絮**：
   - 完美还原了发布会上点缀的台湾在地美食（花娘小馆、王记肉粽、富霸王猪脚、阿婆水果摊、砖窑怀旧餐厅）以及趣味极客彩蛋（爱优的狗、SHENGNI、COLA）。

## 📂 项目结构

```bash
├── index.html                # 主页面结构（支持网格视图、大图交互、全屏研习侧栏等）
├── style.css                 # 霓虹暗黑主题风格与响应式设计
├── app.js                    # 核心数据集 (285个节点) 与过滤器、SVG遮罩控制逻辑
├── generate_directory.py     # 13行完整企业映射名录与精选版生成逻辑
├── generate_all_companies.py # 核心数据编译脚本：自动将名录与高清大图坐标结合，编译输出 app.js
├── partner_directory.md      # 精选核心 50 家企业黄页
├── partner_directory_full.md # 13 行完整 285 家企业黄页目录（Clearbit 高清 Logo 接口）
├── logos/                    # 本地 285 家公司的无损品牌 Logo 图片库
└── ScreenShot_*.png          # 英伟达现场无损大图（用于大图交互底层）
```

## 🚀 快速开始

### 1. 本地浏览
该项目是纯前端无后端的静态页面，克隆后**直接在浏览器中双击打开 `index.html`** 即可开启交互。
- 推荐使用现代浏览器（Chrome / Edge / Safari）以获得最佳的霓虹毛玻璃（Glassmorphism）与 SVG Mask 渲染效果。

### 2. 编译与维护数据
如果需要修改某个企业的描述、生态标签或增加新企业：
1. 编辑 `generate_directory.py` 中的 `partner_rows` 数据集。
2. 运行 Python 编译脚本重新生成 `app.js` 与 markdown 名录：
   ```bash
   python3 generate_all_companies.py
   python3 generate_directory.py
   ```
3. 刷新 `index.html` 即可看到最新的交互数据与排版。
